Что реализовано
---------------
src/avito_candidates/geo_dense.py:
  cosine(query,item) + weight * log P(item_location | search_location)
Географическая оценка вычисляется для всего каталога до dense top449.
Сохранённые fit-only связи сглаживаются расстоянием между центрами локаций:
масса сглаживания3, масштаб40км, нижняя граница вероятности1e-7.
Центры городов берутся из метаданных каталога; центр региона при отсутствии
точного города определяется обучающей историей. При отсутствии истории
географическая поправка равна нулю. Численные признаки dense остаются
исходным cosine; ранг dense отражает новый порядок с географией.

Корпус:200000 объявлений. Сохранённые векторы Octen извлечены из HNSW;
эмбеддинги объявлений не переобучались и не пересчитывались.
Query-only кодирование12103 контекстов заняло около100секунд.
Полный цикл оценки четырёх вариантов:4183.8секунды до bootstrap (~69.7мин).

Общий пул: description449 + dense449 + прежний geo100; свободные места
до998 заполняются прежними typed-title,typed-params,microcategory и
глубоким глобальным dense. Изменён только базовый dense449.
Итоговый location-bonus=0.02, длина128, ef_search1000, channel_quota0;
исходные веса HGB и selected_iteration100 фиксированы.
Это экспериментальный маршрут, запускаемый отдельным скриптом; новые
аргументы основной команды avito здесь не добавлялись.

-------------------

Независимый сумматор сверил все идентификаторы/знаменатели/размеры пулов,
повторно вычислил агрегаты и подтвердил таблицу из результатов по запросам.
