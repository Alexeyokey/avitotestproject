не подбирать веса по закрытому benchmark и не заявлять качество модели.

## Причина ошибки загрузки библиотек

Повторная диагностика 26 сентября подтвердила блокировку политикой Windows,
а не ошибку расчёта TF-IDF или чтения признаков. В журнале
`Microsoft-Windows-CodeIntegrity/Operational` события 3077 указывают на:

- `pandas/_libs/interval.cp312-win_amd64.pyd`;
- `scipy/optimize/_bglu_dense.cp312-win_amd64.pyd`;
- `pyarrow/arrow_compute.dll`;
- `sklearn/utils/murmurhash.cp312-win_amd64.pyd`.

Соседние события 3118 обозначены `Smart App Control Block Deteails`.
Ошибка повторного импорта scikit-learn: «Политика управления приложениями
заблокировала этот файл». Ошибка возникает при импорте, до запуска поиска.

Python и установленные бинарные модули имеют архитектуру AMD64, версия Python —
3.12. Полный импорт pandas 3.0.6 при повторной проверке прошёл; импорт верхнего
пакета pyarrow 25.0.1 также прошёл. Это не подтверждает работоспособность всех
их расширений. Причина изменения поведения pandas не установлена.

Настройки защиты не менялись. Для запуска всех проверок нужно окружение,
в котором эти зависимости разрешены политикой безопасности, либо согласованное
с владельцем политики разрешение. Переустановка пакетов сама по себе не решает
подтверждённую блокировку.
